## Openen in Visual Studio Code

1. Pak het ZIP-bestand uit.
2. Open Visual Studio Code.
3. Kies **File > Open Folder**.
4. Selecteer `my-cybersecurity-journey`.
5. Open `index.html`.

## Live Server

Voor de makkelijkste manier van bekijken:

1. Installeer de VS Code-extensie **Live Server**.
2. Rechtsklik op `index.html`.
3. Kies **Open with Live Server**.

## Privacy

Credential-/referentienummers zijn bewust niet opgenomen in de publieke website.
Publiceer ook geen wachtwoorden, tokens, flags, privégegevens of informatie over
systemen waarvoor je geen toestemming hebt.


## Een nieuwe HTB write-up toevoegen

1. Kopieer `writeups/HTB_WRITEUP_TEMPLATE.md` en vul hem in.
2. Gebruik Markdown als je privé/werkversie in Obsidian of VS Code.
3. Kopieer daarna `writeups/_template.html`, bijvoorbeeld naar `writeups/fawn.html`.
4. Zet alleen de relevante, opgeschoonde informatie in de HTML-pagina.
5. Voeg een kaart met een link toe onder `#writeups` in `index.html`.

Zie `writeups/README.md` voor de volledige workflow.
