Hack The Box — Markup

Een compacte technische write-up over een aanvalsketen via een kwetsbare XML-parser, het uitlezen van een SSH-private key en een Windows privilege-escalatie via een schrijfbaar batchbestand dat met verhoogde rechten wordt uitgevoerd. Flags, doel-IP-adressen en wachtwoorden zijn bewust weggelaten.

Overview

In deze lab lag de focus voornamelijk op web enumeration, XML External Entity (XXE), SSH-toegang en Windows privilege escalation via onveilige bestandsrechten.

Recon → Web Enumeration → XXE → Initial Access → Privilege Escalation

Reconnaissance

Ik begon de machine met mijn Superscanv2-workflow.

PortServiceWaarom interessant?
80/tcpHTTPWebapplicatie aanwezig voor verdere enumeratie
22/tcpSSHMogelijke remote toegang zodra geldige authenticatie beschikbaar is

Omdat er zowel een webapplicatie als een SSH-service bereikbaar was, lag de eerste focus op de webapplicatie om informatie of authenticatiemateriaal te vinden dat later voor SSH gebruikt kon worden.

Enumeration

Na toegang tot de webapplicatie onderzocht ik de functionaliteit en de HTTP-verzoeken die door de applicatie werden verstuurd. Een onderdeel van de applicatie verwerkte invoer als XML.

  • XML-verwerking: gebruikersinvoer werd door een XML-parser verwerkt.
  • XXE: externe XML-entiteiten werden niet veilig uitgeschakeld.
  • Local File Read: hierdoor konden lokale bestanden vanaf het Windows-systeem worden uitgelezen.
  • SSH-key: de private SSH-sleutel van gebruiker daniel kon worden benaderd via C:\Users\daniel\.ssh\id_rsa.
De belangrijkste aanwijzing was dat de XML-parser externe entiteiten accepteerde. Daarmee veranderde een webkwetsbaarheid in een manier om gevoelige lokale bestanden van het systeem uit te lezen.

Initial Access

De XXE-kwetsbaarheid maakte het mogelijk om de private SSH-sleutel van de lokale gebruiker daniel uit te lezen. De sleutel werd lokaal opgeslagen en met passende bestandsrechten gebruikt voor authenticatie tegen de reeds ontdekte SSH-service.

XXE → SSH private key → SSH authentication → toegang als daniel

Hiermee verkreeg ik interactieve toegang tot het Windows-systeem als een gebruiker met beperkte rechten. De private sleutel zelf wordt uiteraard niet in deze write-up gepubliceerd.

Privilege Escalation

Na initial access begon ik met lokale Windows-enumeratie. Daarbij controleerde ik onder andere gebruikersrechten, services, geplande of periodiek uitgevoerde taken, interessante directories en de toegangsrechten op scripts en bestanden.

In C:\Log-Management\ werd het batchbestand job.bat aangetroffen. Het bestand werd periodiek met verhoogde rechten uitgevoerd, terwijl een normale gebruiker het bestand kon wijzigen.

Deze combinatie vormde de privilege-escalatie: door de inhoud van het batchbestand aan te passen, kon bij de volgende uitvoering een reverse shell worden gestart in de context van het verhoogde proces. Daardoor werd uiteindelijk een shell met Administrator-rechten verkregen.

Writable job.bat → elevated execution → reverse shell → Administrator

Attack Path

Superscanv2 / Nmap ↓ HTTP + SSH identificeren ↓ Webapplicatie enumereren ↓ XML-functionaliteit ontdekken ↓ XXE bevestigen ↓ Private SSH-key uitlezen ↓ SSH-toegang als daniel ↓ Lokale Windows-enumeratie ↓ Schrijfbaar job.bat ontdekken ↓ Batchbestand wordt met verhoogde rechten uitgevoerd ↓ Reverse shell ↓ Administrator Access

Wat ik hiervan heb geleerd

  • XXE: een onveilig geconfigureerde XML-parser kan toegang geven tot lokale bestanden op het systeem.
  • Attack chaining: informatie uit een webkwetsbaarheid kan direct bruikbaar zijn voor een andere service zoals SSH.
  • Windows file permissions: een schrijfbaar script dat door een verhoogd proces wordt uitgevoerd kan leiden tot privilege escalation.
Mijn belangrijkste leerpunt uit deze machine is dat de echte impact vaak ontstaat door kwetsbaarheden aan elkaar te koppelen. De XXE alleen gaf nog geen interactieve toegang, maar leverde precies het authenticatiemateriaal op dat nodig was voor SSH. Daarna maakte een lokale rechtenfout de stap naar Administrator mogelijk.
